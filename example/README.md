# V3C Alert Example

This is a comprehensive example demonstrating how to use the `v3c_alert` package in Flutter applications.

## Features Demonstrated

- Success alerts for positive confirmations
- Error alerts for error handling
- Warning alerts for cautionary messages
- Info alerts for informational purposes
- Custom scenarios with different callback handlers

## Running the Example

1. Navigate to the example directory:
   ```bash
   cd example
   ```

2. Get dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```

## What You'll See

The example app provides buttons for each alert type:

- **Success Alert**: Shows a green checkmark with success message
- **Error Alert**: Shows a red error icon with error message  
- **Warning Alert**: Shows an orange warning icon for confirmations
- **Info Alert**: Shows a blue info icon for informational messages
- **Custom Scenario**: Demonstrates a real-world file deletion scenario

Each alert tracks the user's action and displays it at the bottom of the screen.

## Code Structure

The example demonstrates:
- How to import and use the v3c_alert package
- Different ways to handle OK and Cancel button presses
- How to track user interactions with alerts
- Real-world usage scenarios
