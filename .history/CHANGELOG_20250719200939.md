# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to the [Semantic Versioning](https://semver.org/) guidelines.

## [1.0.0] - 2025-07-19

### Added

- Initial release of `v3c_alert` Flutter widget.
- `V3CAlertDialog` widget with the following features:
  - Four alert types: `error`, `warning`, `success`, `info`.
  - Customizable title and description.
  - OK and Cancel buttons with callback support.
  - Optional `onDialogClosed` callback.
